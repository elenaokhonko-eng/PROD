# Resources page copy

## Intro
Authoritative Singapore help, organised for a stressful moment. Start
with "Right now" if the scam just happened.

## Right now (just happened?)

**Stay calm and protect your accounts first.**
Grounding steps and immediate actions — freeze cards, change passwords,
preserve evidence before anything gets deleted.
→ Guide adapted from ScamShield (scamshield.gov.sg)

**Report the crime.**
File a Police report online via SPF e-services
(eservices.police.gov.sg). Your GuideBuoy report gives you the organised
facts to attach. If you or someone else is in immediate danger, call
the Police on **999**.

**Check a suspicious contact.**
Use ScamShield to verify calls, links, and messages before engaging.
Not sure if something is a scam? Call the **ScamShield Helpline: 1799**
(24 hours, free).

**Hotlines, kept short:**
- ScamShield Helpline — **1799** (24/7)
- Police (emergency) — **999**
- Police hotline (non-emergency) — **1800 255 0000**
